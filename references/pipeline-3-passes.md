# Pipeline 3 passes — Détail opératoire

Ce fichier contient le détail complet des trois passes du Miroir Trans-échelle, avec :
- la version *étendue* (quand les skills frères sont installés)
- la version *compacte autonome* (quand ils ne le sont pas)
- les règles de bascule entre les deux modes

---

## PASSE 1 — Lecture symbolique

### Version étendue (skill `fractales-du-destin` disponible)

Invoque le skill avec la formulation :

> *"Lance un tirage Fractales du Destin sur la situation suivante : [résumé en 1-2 phrases]. Format : tirage complet (5 cartes), double voix (Oracle + Gardien), Phrase symbolique FdD finale."*

Récupère la sortie complète et **conserve telle quelle** la structure du tirage. N'altère pas les arcanes tirés.

### Version compacte autonome

Si le skill frère n'est pas disponible, exécute cette procédure compacte :

#### 1. Identification d'archétypes actifs

Détecte **2 à 4 archétypes** parmi le répertoire de base ci-dessous. Choisis ceux qui résonnent le plus avec la dynamique présente, pas avec les acteurs nommés.

**Répertoire de base (extensible)** :

| Archétype | Dynamique |
|-----------|-----------|
| 🌊 **Le Voyageur** | Transition, déplacement, frontière |
| 👑 **Le Souverain** | Affirmation d'autorité, ordre, légitimité |
| 🎭 **Le Bouffon** | Subversion par le rire, retournement, dévoilement |
| 🦉 **Le Sage** | Recul, observation, transmission |
| 🔥 **Le Rebelle** | Rupture, transgression, refus |
| 🛡️ **Le Gardien** | Conservation, protection, vigilance |
| 🌑 **L'Ombre** | Refoulé, non-dit, ce qui revient |
| 🪞 **Le Miroir** | Reflet, double, identification |
| 🌱 **Le Semeur** | Initiation, germe, patience |
| ⚔️ **Le Combattant** | Confrontation, défense, ligne tenue |
| 🌀 **Le Tisseur** | Lien, réseau, médiation |
| 💀 **Le Passeur** | Transformation par perte, deuil, mue |

#### 2. Repérage de motifs

Détecte **2 à 3 motifs** narratifs récurrents. Exemples :
- *Cycle* (répétition d'un même pattern à intervalles)
- *Rupture* (point de bascule brutal)
- *Retournement* (inversion symbolique)
- *Seuil* (passage entre deux états)
- *Spirale* (intensification progressive)
- *Écho* (un événement passé qui résonne dans le présent)

#### 3. Formulation de la Phrase symbolique FdD

Construis une phrase courte (**15 à 30 mots**) qui :
- condense l'intuition centrale
- emploie un registre métaphorique
- évite toute prédiction factuelle
- ouvre une perspective plutôt qu'elle ne ferme

**Exemples de syntaxe :**
- *"Le [archétype] revient là où on l'avait enterré, et il porte le [motif] que personne ne nommait."*
- *"Ce qui semble [apparence] est en réalité un [archétype] qui cherche son seuil."*
- *"Le [motif] s'accélère ; le [archétype] doit choisir entre [tension A] et [tension B]."*

#### 4. Angles d'ouverture

Liste **2 à 3 questions ou perspectives** que cette lecture rend visibles et qui ne seraient pas évidentes par une approche purement analytique.

Exemples :
- *"Et si la décision rationnelle de X était en fait une fidélité à un récit qu'il ne nomme pas ?"*
- *"Qu'est-ce qui, dans la mémoire collective, prépare ce retournement ?"*
- *"Quel mythe ce conflit rejoue-t-il, sans le savoir ?"*

## PASSE 2 — Lecture analytique

### Version étendue (skill `signaux-du-futur` disponible)

Invoque le skill avec la formulation :

> *"Lance une analyse OSINT-Prospective sur le dossier suivant : [résumé + corpus si disponible]. Format : méthodologie 11 étapes complète, hypothèses concurrentes, scénarios prospectifs, biais surveillés."*

Récupère la sortie complète et **conserve la structure analytique**.

### Version compacte autonome (5 étapes condensées)

Si le skill frère n'est pas disponible, exécute cette procédure compacte :

#### 1. Question d'incertitude

Formule **précisément** l'incertitude à réduire. Exemples :
- ❌ Mauvais : *"Que va-t-il se passer en Ukraine ?"* (trop large)
- ✅ Bon : *"Quelle est la probabilité d'une rupture diplomatique majeure entre X et Y dans les 6 prochains mois, et quels indicateurs la précéderaient ?"*

#### 2. Signaux faibles

Liste **3 à 5 éléments** dans le dossier qui relèvent de :
- **Dissonance** : un acteur dit X mais agit Y
- **Anomalie** : un événement statistiquement rare dans ce contexte
- **Glissement lexical** : un changement de vocabulaire significatif
- **Silence significatif** : ce qui n'est pas dit, ce qui est évité
- **Répétition** : un motif qui revient sans qu'on l'ait théorisé

Marque chaque signal de sa source et de son degré de fiabilité.

#### 3. Hypothèses concurrentes

Formule **exactement 3 hypothèses structurellement distinctes** (pas trois variantes de la même intuition).

Règle : si l'hypothèse H1 et l'hypothèse H2 conduisent aux mêmes prédictions à 6 mois, **ce n'est qu'une seule hypothèse**. Reformule.

Exemple de tripartition saine :
- H1 : *"Acteur X cherche à provoquer une escalade contrôlée pour renforcer son pouvoir interne."*
- H2 : *"Acteur X subit une pression qu'il ne maîtrise pas et improvise."*
- H3 : *"Acteur X prépare un retrait stratégique masqué par une apparente fermeté."*

Ces trois hypothèses produisent **des prédictions différentes** et **des indicateurs de validation différents**.

#### 4. Scénarios prospectifs

Pour chaque hypothèse, esquisse un scénario en 2-3 phrases :
- **Optimiste** : que se passe-t-il si la dynamique se résout favorablement ?
- **Probable** : que se passe-t-il selon la pente dominante actuelle ?
- **Critique** : que se passe-t-il si tout dégénère ?

Pour chaque scénario, identifie **1 à 2 indicateurs de bascule** — événements ou seuils dont l'apparition signalerait qu'on bascule dans ce scénario.

#### 5. Biais à surveiller

Liste **1 à 2 biais cognitifs** qui menacent particulièrement cette analyse. Exemples fréquents :
- **Biais de confirmation** : on cherche ce qui valide notre hypothèse préférée
- **Effet miroir** : on prête à l'autre nos propres logiques
- **Ancrage** : la première information reçue surpondère
- **Pensée de groupe** : on s'aligne sur le consensus implicite
- **Biais de récence** : l'événement récent éclipse les tendances longues

Pour chaque biais, indique **une contre-mesure concrète** (ex : ACH = Analysis of Competing Hypotheses, devil's advocacy, red team).

## PASSE 3 — Carte de résonance

Cette passe est traitée en détail dans `carte-resonance.md`.

Résumé opératoire :

1. **Aligner** les éléments de P1 et P2 dans un tableau croisé.
2. **Typer** chaque ligne : convergence forte / faible / dissonance / angle mort.
3. **Lire** chaque ligne : qu'est-ce que ce croisement révèle ?
4. **Synthétiser** en quatre catégories : verrouillé / dissonant / angles morts / recommandations.

**Règle d'or** : la P3 ne doit produire **aucun élément nouveau**. Elle structure, elle ne crée pas. Tout élément de P3 doit être traçable à un élément précis de P1 ou de P2.

## Règles de bascule entre modes

### Bascule mode étendu → mode compact

Si l'invocation d'un skill frère échoue ou retourne une sortie incomplète :
- Notifier l'utilisateur dans la sortie : *"[Mode compact activé pour la passe X — skill frère indisponible]"*
- Exécuter la version compacte
- Suggérer en fin de sortie : *"Pour une lecture étendue, installer le skill `fractales-du-destin` / `signaux-du-futur`."*

### Bascule mode complet → mode partiel

Si le dossier ne contient pas assez de matière pour P2 (ex : pas de corpus factuel, juste une intuition personnelle) :
- Demander à l'utilisateur s'il souhaite **uniquement** une lecture symbolique
- Ou s'il préfère **fournir un corpus** pour permettre la P2

Ne jamais exécuter une P2 sans matière factuelle suffisante — cela produirait une analyse fausse-rigoureuse, exactement le glissement que le skill cherche à éviter.
